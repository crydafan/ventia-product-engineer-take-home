# Product Engineer starter

Desde la raíz del starter, instala dependencias y ejecuta la aplicación con pnpm:

```bash
pnpm install
pnpm --filter web dev
pnpm --filter web build
pnpm --filter web typecheck
```

La interfaz usa tipografías del sistema y no descarga fuentes durante el build.

La [guía principal del reto](../README.md) contiene las reglas del pedido, la configuración y el contrato de la API.
